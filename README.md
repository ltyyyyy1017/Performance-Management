# 粤港联绩效登记管理系统

仅供内务部部长、内务部部员操作的绩效管理网页。五部门成员是被管理对象，不开设系统账号。

## 核心操作

1. 部长在“成员与权限”分配部员负责部门。
2. 部长创建自由项大项目，并授权内务部部员。
3. 部员进入获授权大项目，为自己负责部门的人员创建小项目，填写分工、积分及成果材料。
4. 部长创建固定任务、指定适用成员与收集部员；部员收集负责部门材料并登记完成情况。
5. 查看月度绩效，按部门筛选并导出CSV。

页面只保留工作台、自由项项目、固定项收集、绩效报表、成员与权限。没有“核对与审核”和“考核设置”页面，登记直接计分。

## 本地运行

本项目无构建依赖，使用现代浏览器打开 `dist/index.html` 即可。推荐使用任意静态HTTP服务器托管 `dist/`，例如已安装Python时：

```sh
python -m http.server 8000 --directory dist
```

访问 http://localhost:8000 。有Node.js时运行逻辑检查：

```sh
node --check dist/app.js
node check.cjs
```

右上角可切换演示操作人。部长查看全部部门；示例部员A负责宣传部、公关部，部员B负责策划部、会务部、内务部。部长可以修改分配。

## 当前交付边界

- 单页静态应用，HTML/CSS与原生JavaScript，无后端。
- 数据保存在浏览器localStorage的`ygl-v2`键中；同一域名、同一浏览器共享本地数据，不跨设备同步。
- 角色切换与部门限制用于演示业务规则，尚非服务器身份认证和安全隔离。
- 图片和PDF附件以Data URL保存，每个附件限1MB，浏览器总存储容量仍有限。
- OCR尚未接入，支持人工选人、材料上传、异常标记和完成登记。
- 报表目前为选定月份的个人汇总及CSV，累计历史、Excel工作簿和详细任务导出仍待实现。
- 自由项统一目标默认8分，任务总积分由操作者录入；1/2/4分规则尚未做成完整任务标准库。
- 删除、批量导入、成员转部门历史管理、备份恢复界面尚未实现。

详细业务、权限、数据模型、计分、部署与后端演进见 [完整系统架构](docs/系统设计架构.md)。

## 目录

```text

dist/app.js               业务、交互、部门权限、计算与本地存储
check.cjs                 部门范围与越权写入回归检查
docs/系统设计架构.md      系统架构与当前实现说明
```

GitHub部署可将`dist`目录交给任意静态托管平台；如使用GitHub Pages，可通过Actions上传该目录。仓库不包含生产数据、访问令牌或Sites项目绑定。
